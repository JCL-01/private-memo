# 프라이빗 메모 PRD

| 항목 | 내용 |
|---|---|
| 문서 버전 | v0.1 (2026-11-19) |
| 상태 | MVP 완료 (1~4단계) |
| 플랫폼 | Android, Windows (이후 iOS) |
| 저장소 | `JCL-01/private-memo` |

---

## 1. 개요

### 1.1 문제
지하철, 회의실, 카페처럼 옆에 사람이 있는 곳에서 메모를 쓰면 화면 내용이 그대로 노출된다.
기존 메모 앱은 앱 전체를 잠그는 기능은 있지만, **쓰는 도중의 화면**을 가려 주지는 않는다.

### 1.2 해결 방법
- **프라이빗 모드**: 지금 쓰고 있는 어절과 바로 앞뒤 한 어절씩만 보이고, 나머지는 길이만 나타내는 회색 박스로 가린다.
- **프라이빗 드래그**: 일반 메모에서 원하는 부분만 골라 박스로 가려 두고, 해제할 때까지 계속 가린다.
- 글을 쓰는 흐름은 해치지 않는다. 가린 상태에서도 오타를 찾아 고치고, 원하는 어절만 잠깐 열어 볼 수 있다.

### 1.3 목표
- 옆 사람이 화면을 봐도 메모 내용을 알 수 없게 한다.
- 가린 상태에서도 일반 메모 앱만큼 자연스럽게 쓰고 고칠 수 있게 한다.
- 메모 내용은 외부 서버로 나가지 않는다. 저장과 AI 처리는 기기 안에서 하고, 맞춤법은 기기(OS)에 내장된 검사를 쓴다.

### 1.4 대상 사용자
- 공공장소나 회의 중에 개인적인 내용을 메모하는 사람.
- 통화나 대화 중에 핵심만 빠르게 받아 적는 사람 (향후 AI 정리 모드의 주 사용자).

## 2. 용어

| 용어 | 정의 |
|---|---|
| 어절 | 공백 문자(스페이스, 줄바꿈 등)로 나뉜 텍스트 단위 |
| 박스 | 어절의 글자 대신, 글자 길이만큼의 회색 박스로 표시한 상태 |
| 현재 어절 | 커서가 있는 어절 |
| 가린 범위 | 프라이빗 드래그로 가려 둔 어절들. 메모에 저장된다 |
| 보기 | 박스 하나를 잠시 열어 보는 일시적 상태. 저장하지 않는다 |
| 수정 | 박스 어절들의 박스를 풀어(파란색) 편집하는 상태. `수정 완료`로 끝낸다 |

## 4. 기능 요구사항

### F1. 기본 메모 (아이폰 메모 앱 형식)

| ID | 요구사항 |
|---|---|
| F1-1 | 메모 목록은 최근 수정한 메모가 위에 오도록 정렬한다 |
| F1-2 | 목록 항목은 제목(비어 있지 않은 첫 줄), 수정 날짜, 미리보기(둘째 줄)를 보여 준다. 날짜는 오늘이면 시각, 어제면 "어제", 그 외에는 날짜로 표시한다 |
| F1-3 | 목록 하단에 메모 개수와 새 메모 버튼을 둔다 |
| F1-4 | 메모 삭제: 목록에서 밀기, 길게 누르기(PC: 우클릭) 메뉴, 편집 화면의 삭제 버튼 |
| F1-5 | 입력이 멈추면 자동 저장한다 |
| F1-6 | 내용 없이 나온 새 메모는 남기지 않는다 |
| F1-7 | 목록의 제목·미리보기에서도 프라이빗 드래그로 가린 부분은 박스로 가린다 |
| F1-8 | 라이트 모드와 다크 모드를 지원한다 (시스템 설정을 따름) |

### F1F. 폴더

| ID | 요구사항 |
|---|---|
| F1F-1 | 메모는 폴더에 담긴다. 첫 화면은 폴더 목록이며, 폴더마다 메모 개수를 보여 준다 |
| F1F-2 | 기본 폴더: `메모`(기본 저장 폴더), `빠른 메모`(정리 기능이 있는 폴더, F8-2), `최근 삭제된 항목`. 기본 폴더는 이름을 바꾸거나 지울 수 없다 |
| F1F-3 | 사용자가 폴더를 만들고, 이름을 바꾸고, 지울 수 있다. 폴더를 지우면 안의 메모는 `최근 삭제된 항목`으로 간다 |
| F1F-4 | 메모를 다른 폴더로 옮길 수 있다(목록의 길게 누르기·우클릭 메뉴, 편집 화면 메뉴) |
| F1F-5 | 메모를 삭제하면 `최근 삭제된 항목`으로 간다. 30일이 지나면 자동으로 영구 삭제된다 |
| F1F-6 | `최근 삭제된 항목`에서는 메모를 복구(원래 폴더로, 원래 폴더가 없으면 `메모`로)하거나 바로 영구 삭제할 수 있다. 이 폴더의 메모는 읽기만 할 수 있다 |
| F1F-7 | 아무것도 쓰지 않은 새 메모는 `최근 삭제된 항목`에 남기지 않고 바로 없앤다 |

### F2. 프라이빗 모드

메모 단위로 켜고 끈다. 켜진 상태는 메모에 저장된다.

| ID | 요구사항 |
|---|---|
| F2-1 | 현재 어절은 검은색(다크 모드: 흰색)으로 표시한다 |
| F2-2 | 현재 어절 바로 앞과 바로 뒤의 한 어절씩만 회색으로 표시한다 |
| F2-3 | 나머지 어절은 모두 박스로 표시한다 |
| F2-4 | 줄 구조(줄바꿈, 공백)는 그대로 유지한다. 어절이 박스로 바뀔 뿐이다 |
| F2-5 | 기기 맞춤법 검사가 틀렸다고 한 어절에는 밑줄을 표시한다. 박스 상태인 어절에도 표시하며, 박스가 밑줄을 가리지 않는다 (F6) |
| F2-6 | `최근` 버튼: 가장 최근에 수정하거나 추가한 어절로 커서를 옮긴다 |
| F2-7 | `마지막` 버튼: 문서의 마지막 어절로 커서를 옮긴다 |
| F2-8 | `해제` 버튼: 프라이빗 모드를 끄고 일반 메모로 전환한다. 일반 메모의 `프라이빗` 버튼으로 다시 켠다 |
| F2-9 | 프라이빗 모드에서는 프라이빗 드래그로 가린 어절이라도 현재 어절과 바로 앞뒤 한 어절씩은 항상 보인다 (F2-1, F2-2의 색 규칙을 따름) |
| F2-10 | 프라이빗 모드에서는 어절이나 어절 사이 빈 곳을 클릭·터치해도 커서와 현재 어절이 바뀌지 않는다. 현재 어절은 `수정`, `최근`, `마지막`으로만 바꾼다. 현재 어절 안에서의 커서 이동(방향키 등)과 길게 누르기·드래그로 범위 선택은 할 수 있다 |
| F2-11 | 프라이빗 모드 하단 바의 `최근`·`마지막` 오른쪽에 ◀ ▶ 화살표를 두고, 현재 어절을 이전·다음 어절로 옮길 수 있다 |

### F3. 프라이빗 드래그 (일반 모드)

| ID | 요구사항 |
|---|---|
| F3-1 | 텍스트를 드래그(선택)하면 메뉴가 뜨고, `프라이빗`을 고르면 선택 범위에 걸친 어절을 박스로 가린다 |
| F3-2 | 선택이 어절 중간에서 시작하거나 끝나도, 걸친 어절 전체를 가린다 |
| F3-3 | 드래그 범위에 박스가 일부라도 걸치면 메뉴에 `해제`가 나오고, 고르면 걸친 박스를 모두 푼다 (일반 모드만) |
| F3-4 | 가린 범위는 메모에 저장되어, 메모를 닫거나 앱을 다시 켜도 유지된다 |
| F3-5 | 가린 범위의 근처나 중간에 새로 입력한 글자는 가리지 않는다 |
| F3-6 | 가린 부분도 복사할 수 있다 |
| F3-7 | 가린 부분도 지울 수 있다. 한 글자씩 지워지고, 박스 길이만 줄어든다 |
| F3-8 | 가린 범위 앞에서 글자를 넣거나 지워도 가린 범위는 원래 어절을 따라간다 |

### F4. 박스 공통 동작 (일반 모드·프라이빗 모드 모두)

| ID | 요구사항 |
|---|---|
| F4-1 | 박스를 길게 누르거나(PC: 우클릭) 드래그 범위에 박스가 일부라도 걸치면, 메뉴에 `수정`·`보기`·`해제`가 뜬다. 프라이빗 모드에서는 `수정`·`보기`만 뜬다 |
| F4-1a | 드래그 범위에 가리지 않은 어절도 섞여 있으면 `프라이빗`도 함께 뜬다 (일반 모드만). 프라이빗 모드에서는 `프라이빗` 메뉴가 없다 |
| F4-1b | 박스 메뉴에도 복사·잘라내기·붙여넣기 등 기본 메뉴를 함께 둔다 |
| F4-1c | 프라이빗 모드에서는 드래그로 가린 어절이 아니어도, 박스로 보이는 어절은 모두 `수정`·`보기` 대상이다 |
| F4-2 | `수정`: 드래그 범위(또는 길게 누른 박스 하나)에 걸친 모든 어절의 박스가 풀리고 파란색 글자로 보이며, 그 어절들을 편집할 수 있다(수정 모드). 커서는 첫 어절 끝에 놓인다 |
| F4-2a | 수정 모드에서는 화면 아래 가운데에 파란색 `수정 완료` 버튼이 보인다. 이전·다음 이동 화살표는 없다 |
| F4-2b | 수정 모드는 `수정 완료`(PC는 Esc도)를 눌러야만 끝난다(`보기`와 다름). 커서가 다른 곳으로 가도 수정 범위의 어절들은 보이는 채로 유지된다. 끝나면 어절들은 다시 박스가 되고 버튼은 사라진다 |
| F4-2c | 수정 중인 어절 밖에서 입력한 글자는 가리지 않는다(F3-5) |
| F4-2d | 프라이빗 모드에서 수정 모드를 끝내면, 수정 모드에 들어가기 전 커서 위치(현재 어절)로 돌아간다. 수정 모드 중에는 수정 범위의 어절로 커서를 옮길 수 있다 |
| F4-2e | 수정 중인 어절을 모두 지워도 수정 모드는 끝나지 않는다. 그 자리에서 다시 쓴 글자는 여전히 수정 대상이며, 드래그로 가린 어절이었다면 계속 가린 상태(프라이빗)로 남는다 |
| F4-3 | `수정` 중 어절 중간에 공백 문자(스페이스, 줄바꿈 등)를 넣어 나누면, 나뉜 두 어절은 둘 다 가린 상태로 남는다 |
| F4-4 | `보기`: 범위에 걸친 박스들만 풀려 주황색 글자로 보인다. 화면을 다시 누른 뒤 손가락(마우스)을 떼면 다시 박스가 된다. 누르고 있는 동안에는 가리지 않는다 |
| F4-5 | `보기` 상태는 저장하지 않는다 |
| F4-6 | 박스를 짧게 누르면 누른 위치에 따라 커서가 박스 바로 앞이나 바로 뒤에 놓인다. 박스 안으로는 들어가지 않는다 |
| F4-7 | 박스 어절의 내용은 `수정` 메뉴 또는 `해제`로만 고칠 수 있다 |
| F4-8 | 박스에서 잠시 벗어난 어절의 색: `수정` 중은 파란색, `보기` 중은 주황색 |
| F4-9 | 박스는 모두 같은 높이(글자 크기 정도)로 그리고, 위아래 줄의 박스와 겹치거나 붙지 않게 한다 |
| F4-10 | PC에서는 Esc 키로 수정 모드와 `보기`에서 빠져나온다 |

### F5. 되돌리기 / 다시 실행

| ID | 요구사항 |
|---|---|
| F5-1 | 편집 화면에 되돌리기, 다시 실행 버튼을 둔다 |
| F5-2 | 단축키: 되돌리기 `Ctrl+Z`, 다시 실행 `Ctrl+Y` 또는 `Ctrl+Shift+Z` |
| F5-3 | 되돌리기 대상: 글자 입력·삭제, 프라이빗 드래그의 `프라이빗`·`해제`, `수정`으로 고친 내용. 되돌리면 글자, 커서 위치, 가린 범위가 모두 직전 상태로 돌아간다 |
| F5-4 | 되돌리기 대상이 아닌 것: `보기`, 프라이빗 모드 켜기·끄기, 커서 이동(`최근`·`마지막` 포함) |
| F5-5 | 글자 입력은 어절 단위로 묶어 되돌린다. 한글 조합 중인 글자는 하나의 입력으로 본다 |
| F5-6 | 되돌린 뒤 새로 편집하면 다시 실행 기록은 사라진다 |
| F5-7 | 기록은 메모를 열어 둔 동안만 유지한다 |

### F6. 맞춤법 검사

| ID | 요구사항 |
|---|---|
| F6-1 | 앱에 자체 맞춤법 사전·엔진을 넣지 않고, 모바일·PC 기기(OS)에 내장된 맞춤법 검사를 쓴다 |
| F6-2 | 기기 맞춤법 밑줄은 박스 상태인 어절에도 그대로 보인다. 박스가 밑줄을 가리지 않는다 |
| F6-3 | 박스는 이 앱 화면에만 그려진다. 기기에는 박스가 없는 원래 글자가 그대로 전달되어, 기기 맞춤법 검사와 대체 단어 기능이 평소처럼 동작한다 |
| F6-4 | 밑줄 친 어절을 짧게 누르면 기기의 대체 단어 메뉴가 뜬다(아이폰·안드로이드). 박스 어절이어도 마찬가지이며, 이때 커서를 박스 앞뒤로 옮기지 않는다. 프라이빗 모드에서도 현재 어절은 바뀌지 않는다 |
| F6-5 | 대체 단어로 바꾼 어절이 드래그로 가린 어절이면 계속 가린다. 프라이빗 모드에서는 바꾼 뒤에도 현재 어절과 커서가 그대로다 |
| F6-6 | 윈도우: Flutter가 윈도우 기기 맞춤법을 지원하지 않으므로, 윈도우 내장 맞춤법 API(ISpellChecker)를 앱에서 직접 연결한다. **윈도우는 영어만 검사하고 한국어는 검사하지 않는다**(윈도우에 한국어 맞춤법 검사기가 없음, 결정됨). 영어 검사에는 윈도우 영어 언어팩이 필요하다. 한글 어절에는 밑줄을 긋지 않는다. 밑줄 어절을 우클릭하면 메뉴 맨 위에 대체 단어가 뜬다 |
| F6-7 | MVP 이후: 내장 소형 AI 모델로 문법·띄어쓰기 오류까지 밑줄을 표시한다 (F8 참고) |

### F8. 기기 안 AI (MVP 이후)

앱에 작은 오픈 모델을 넣어 기기 안에서 실행한다. 모든 기기에서 같은 기능을 제공하기 위해 플랫폼별 AI(Gemini Nano, Phi Silica)에 의존하지 않는다.

| ID | 요구사항 |
|---|---|
| F8-1 | 문법·띄어쓰기 검사 (F6-7) |
| F8-2 | **빠른 메모 정리**: `빠른 메모` 폴더의 메모에는 `정리` 버튼이 있다. 회의·통화 중 러프하게 적은 메모를 누르면 내장 AI가 정리한다 |
| F8-2a | 정리하면 원본 글이 `원본` 박스에 담기고, 그 바로 아래 같은 모양의 `정리본` 박스가 생긴다 (채팅 답변의 코드 블록처럼 상단 바가 있는 박스) |
| F8-2b | 박스 상단 바: 왼쪽에 라벨(`원본` / `정리본`), 오른쪽에 순서대로 ✕(삭제), 가위(잘라내기), 복사 버튼 |
| F8-2c | 정리본이 생기면 화면이 정리본으로 내려가 초점이 맞춰진다. 박스의 상단 바가 화면 위로 올라가 안 보이게 되면 바가 그 박스의 하단으로 내려와 보인다 |
| F8-2d | 정리 형식: `요약` + `할 일`. 할 일에 일정(날짜·시간)이 있으면 그 항목 뒤에 괄호로 붙이고(예: `(내일 3시)`), 이어 적은 물건 목록 등은 세부 내용으로 붙인다. 원본에 할 일이 없으면 `할 일`은 빼고 요약만 쓴다. **할 일 고르기와 날짜는 규칙(코드)으로, 요약은 내장 AI 모델로 만든다** (작은 모델은 할 일을 잘 가리지 못함 — 시험 결과. 요약을 먼저 만든 뒤 요약에서 할 일을 뽑는 방식도 시험했으나 요약 단계에서 할 일·날짜가 빠지거나 바뀌어 더 나빴음) |
| F8-2h | 역할 나누기: 다른 사람이 맡은 일(`요리는 누나가`, `(지수 담당)`, `김팀장님이 …`, `엄마가 …`)은 빼지 않고 그 사람의 할 일로 정리한다. 맡은 사람이 둘 이상이면 `[나]`, `[누나]`처럼 사람별로 나눠 쓴다 |
| F8-2e | 되돌리기를 누르면 정리 전 상태로 돌아간다 |
| F8-2f | 원본에 프라이빗 드래그로 가린 내용이 있으면 정리본 전체를 박스로 가린다. 정리본 바에 `해제` 버튼이 생기고, 누르면 정리본 전체가 보이며 버튼이 `가리기`로 바뀐다. `가리기`를 누르면 다시 가린다 |
| F8-2g | 날짜 표현("다음 주 화요일")은 모델이 뽑고, 실제 날짜 계산은 코드가 한다. 이후 자동 일정 등록(캘린더)에 같은 결과를 쓴다 |
| F8-3 | 내장 AI는 llama.cpp(GGUF)로 기기 안에서 실행하고, 요약에 쓴다. 모델: **Kanana-2 1.3B**(4비트 0.85GB, 한국어 요약이 자연스럽고 빠름). 앱에 넣지 않고 처음 쓸 때 내려받는다(메모 내용은 기기 밖으로 나가지 않음). 시험 기록: Qwen3 1.7B·4B, Gemma 3n E2B, Kanana-2 1.3B·3B 비교 |
| F8-4 | 이후: 캘린더·체크리스트 기능, 빠른 메모에서 자동 일정 등록, 문법·띄어쓰기 검사와 설명 |

## 5. 비기능 요구사항

### 6.1 데이터 모델

| 필드 | 타입 | 설명 |
|---|---|---|
| id | 문자열 (UUID) | 기본 키 |
| content | 문자열 | 메모 본문 |
| privateMode | 불리언 | 프라이빗 모드 켜짐 여부 |
| hiddenRanges | 문자열 (JSON 배열) | 가린 범위 목록 |
| createdAt | 날짜 | 생성 시각 |
| updatedAt | 날짜 | 마지막 수정 시각 |
| folderId | 문자열 | 담긴 폴더 (기본 `notes`) |
| deletedAt | 날짜(없을 수 있음) | `최근 삭제된 항목`으로 옮긴 시각 (30일 뒤 영구 삭제) |
| previousFolderId | 문자열(없을 수 있음) | 삭제 전 폴더 (복구용) |

| blocks | 문자열 (JSON 배열) | 정리 기능의 원본·정리본 박스 (본문 위에 놓임) |

Folders 테이블: id, name, isSystem(기본 폴더 여부), createdAt. 기본 폴더 id: `notes`(메모), `quick`(빠른 메모), `trash`(최근 삭제된 항목). DB 버전 3(1 → 2: 폴더 추가, 기존 메모는 `메모` 폴더로 / 2 → 3: blocks 추가).

### 6.2 에디터 구조 원칙
- 에디터 상태는 **글자 + 커서 위치 + 가린 범위**를 한 묶음으로 다룬다. 되돌리기 기록도 이 묶음 단위로 남긴다.
- 화면 표시(박스, 회색 단계, 밑줄)는 저장된 상태에서 매번 계산한다. `보기`와 `수정` 같은 일시적 상태는 저장하지 않는다.
- 가린 범위는 편집이 일어날 때마다 위치를 다시 계산해 원래 어절을 따라가게 한다.
