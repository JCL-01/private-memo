# 프라이빗 메모 — MVP 기능 명세

옆 사람이 보면 안 되는 내용을 적을 때 쓰는 메모 앱.
대상 플랫폼: Android, Windows (이후 iOS).

용어
- **어절**: 공백 문자(스페이스, 줄바꿈 등)로 나뉜 단위.
- **박스**: 어절의 글자 대신 글자 길이만큼의 회색 박스로 표시한 것.
- **현재 어절**: 커서가 있는 어절.

## 1. 기본 기능 (아이폰 메모 앱 형식)
- 메모 목록(최근 수정 순), 새 메모 만들기, 메모 삭제.
- 목록 항목: 첫 줄 = 제목, 둘째 줄 = 미리보기, 수정 날짜.
- 삭제: 목록에서 밀기 / 길게 누르기·우클릭 메뉴 / 편집 화면의 삭제 버튼.
- 내용 없이 나온 새 메모는 남기지 않는다.
- 목록의 제목·미리보기에서도 프라이빗 드래그로 가린 부분은 박스로 가린다.

## 2. 프라이빗 모드 (메모 단위로 켜고 끔)
- 현재 어절: 검은색(다크 모드에서는 흰색).
- 직전 어절은 회색, 그 앞 어절은 더 옅은 회색. (앞쪽 두 어절만 보임)
- 나머지 어절: 박스.
- 줄 구조는 그대로 유지한다. 어절이 박스로 바뀔 뿐이다.
- 맞춤법이 틀린 어절에는 밑줄을 표시한다(박스 위에도).
- `최근` 버튼: 최근에 수정/추가한 어절로 이동.
- `마지막` 버튼: 문서의 마지막 어절로 이동.
- `해제` 버튼: 일반 메모로 전환. 일반 메모의 `프라이빗` 버튼: 프라이빗 모드로 전환.

## 3. 프라이빗 드래그 (일반 모드)
- 드래그(선택)하면 메뉴가 뜨고 `프라이빗`을 고르면 선택 범위에 걸친 어절 전체를 박스로 가린다.
  어절 중간에서 시작·끝나도 걸친 어절 전체가 가려진다.
- 드래그 후 `해제`를 고를 때까지 계속 가려지고, 메모를 닫거나 앱을 다시 켜도 유지된다.
- 가린 범위 근처나 중간에 새로 입력한 내용은 가려지지 않는다.
- 가린 부분도 복사·삭제할 수 있다. 지울 때는 한 글자씩 지워지고, 박스 길이만 줄어든다.

## 4. 박스 공통 동작 (일반 모드·프라이빗 모드 모두)
- 박스를 **길게 누르기**(PC: 우클릭) → `수정`, `보기` 메뉴.
  - `수정`: 그 어절이 현재 어절이 되어 내용이 보이고 편집할 수 있다.
    커서가 그 어절을 벗어나면 다시 박스가 된다.
    수정 중 어절 중간에 공백 문자를 넣어 나누면 나뉜 어절은 둘 다 가려진 상태로 남는다.
  - `보기`: 그 어절만 박스가 풀린다. 한 번 더 짧게 누르면 다시 박스가 된다.
    저장하지 않는 일시적 상태다.
- 박스를 **짧게 누르기** → 누른 위치에 따라 커서가 박스 바로 앞이나 바로 뒤에 놓인다.
  박스 안으로 커서가 들어가지 않는다.
- 박스 어절의 내용 수정은 `수정` 메뉴 또는 드래그 `해제`로만 한다.
- 현재 어절은 언제나 그대로 보인다(가린 어절이라도).

## 5. 맞춤법 검사
- 기기 안에서만 검사한다(메모 내용을 외부로 보내지 않는다).

## 6. 동기화 (MVP 이후)
- 별도 서버 없음. 사용자 본인의 클라우드(Google Drive 앱 전용 폴더 등)로 동기화.

## 개발 단계
1. 프로젝트 구조, 메모 목록·생성·삭제, 로컬 저장, CI 빌드 ✅
2. 프라이빗 드래그 + 박스 공통 동작
3. 프라이빗 모드
4. 맞춤법 밑줄
5. 클라우드 동기화
